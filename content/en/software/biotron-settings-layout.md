Select the device-shaped **Biotron settings** button on [Biotron](https://biotron.playtronica.com). In the compact interface, settings are grouped by purpose. Each dropdown has its name and an **i** hint above it.

> ℹ️ This guide describes the compact interface. The older Settings site and a main-site version awaiting this interface may look different. The layout does not identify your firmware version or require an update.

## Which group contains my setting?

| Group | What you find there |
|---|---|
| **Plant sensor** | Plant-note mute, tempo, note duration, starting note, and scale. |
| **More fun** | Plant MIDI channel, touch-button mode, swing, Humanize, and additional signal-processing settings. |
| **Light sensor** | Light-note mute, Humanize, Pitch bend, light MIDI channel, rhythm, and note range. |

On a wide screen, controls appear in rows of up to four. On a narrow screen, rows contain up to two. A group's last row may have fewer controls. Rotating your phone can change the number of controls in a row.

If a label is unclear, open its **i** hint. Scroll inside the panel to reach the lower groups. See [Reading settings hints](/software/biotron-settings-hints/) for pointer, touch, and keyboard controls.

## Where do my changes go?

| Button | What it does |
|---|---|
| **Check saved settings** | Reads settings from the plugged-in Biotron. |
| **Save preset** | Saves a set of values in this browser. |
| **Load preset** | Puts a selected preset into the page's fields. |
| **Send to device** | Sends the prepared set to the plugged-in device. |

Saving or loading a browser preset does not by itself mean it has been applied to Biotron. However, changing an individual control after reading the device's settings may send that change immediately. Read the status message above the groups.

## My settings look different

Check which site and interface you opened. This guide describes the compact version of the new Biotron site. The older Settings interface may arrange controls differently.

For the existing Settings route and device setup, see the [Biotron guide](/devices/biotron/#configure-save-then-close-settings).
