In the new [Biotron](https://biotron.playtronica.com) interface, select the device-shaped **Biotron settings** button. An **i** beside each setting name opens a short explanation.

> ℹ️ This guide applies to the interface with **i** buttons. The older Settings site and versions without these buttons look different. Do not update firmware because a hint is missing.

## How do I open and close a hint?

- **With a pointer:** hover over **i**. Click to keep the text open.
- **On a touch screen:** tap **i**.
- **With a keyboard:** press **Tab** until **i** has focus. The explanation opens on focus.

Select a pinned hint again, or select outside it, to close it. **Esc** closes the hint first. Another press may close the settings window.

Opening another hint closes the previous one. Scrolling also closes a hint; open it again if needed.

## Will reading a hint change the sound?

Selecting **i** only displays text. It does not change the setting or send it to Biotron.

Changing a knob or dropdown is a separate action. If Biotron is plugged in and its settings have been read, a changed value may be sent immediately. Use **i** to read; change a control when you want to change Biotron's behaviour.

## What do the names mean?

| Name | What the hint explains |
|---|---|
| **The beat** | The tempo of plant notes. |
| **Note hold** | Note duration relative to the beat. |
| **Scale** | The set of notes used for the melody. |
| **Humanize** | Variation in note MIDI velocity between the chosen minimum and maximum. |

Plant and light settings belong to separate groups. If a name appears twice, check which sensor the group controls.

For the groups and preset buttons, see [Biotron settings layout](/software/biotron-settings-layout/).

## There are no i buttons

Compare the page address and interface with this guide. The older Settings site and the main Biotron site may show a different version. Missing hints do not require a firmware update.
